1. Create Project Folder//Do directly on desktop..
mkdir college-admission-api
cd college-admission-api

2. Initialize Node Project //no need to run if directly copied
npm init -y

3. Install Required Packages
npm install express mongoose nodemon

4. Create Files
Create these files:
college-admission-api
│
├── server.js
├── package.json
└── models
    └── Student.js
